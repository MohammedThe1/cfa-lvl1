# مدار — CFA Level I

> النشر العام بطلب المستخدم بتاريخ 2026-10-28: أُضيف بنك الأسئلة وصور صفحات التطبيق إلى المشروع للنشر عبر GitHub Pages. تفاصيل الإعداد والحالة في [دليل النشر](docs/publication.md). وصف الملفات الخاصة أدناه يوثق مرحلة التوزيع السابقة.

تطبيق دراسة شخصي يعمل في المتصفح بواجهة إنجليزية افتراضيًا وزر ترجمة عربية. تبقى الأسئلة والشروح الأصلية بالإنجليزية عند تبديل الواجهة. اختر موضوعًا ثم وحدة، أجب واعرض شرح المصدر، أو استخدم المفضلة والمراجعة والاختبارات المؤقتة.

**تحديث التحويل:** أُفرغ نص 5,382 صفحة من 10 مجلدات CFA و4 كتب Schweser، جميعها إصدار 2027، وفُصل 1,558 بندًا. يتضمن البنك المحلي الأسئلة الجاهزة للتدريب بصفحاتها الأصلية، مع قسم منفصل للبنود المعلّقة. الأعداد النهائية وحدود التحقق في [حالة التحويل](docs/conversion-status.md). حُفظت أسئلة العينة الـ11 ومعرّفاتها دون تغيير. ملفات البنك والصور خاصة ومستبعدة من Git؛ لا يحتويها checkout نظيف وحده. لم تُستورد أسئلة من حساب LES الحقيقي.

## التشغيل على جهازك

ثبّت Node.js حديثًا (22.12 أو أحدث؛ اختُبر على 24.19)، وافتح الطرفية داخل مجلد المشروع، ثم:

```sh
npm ci
npm run dev
```

افتح العنوان الذي يظهر في الطرفية. في هذه البيئة مسار المشروع `/workspace/cfa-lvl1`. لا حاجة لحساب أو مفاتيح API. يتطلب تثبيت الحزم اتصالًا بالإنترنت؛ لا يجلب التطبيق أسئلة أو خطوطًا من خدمات خارجية أثناء استخدامه.

## الاستخدام

1. افتح التطبيق؛ يُحمّل البنك الخاص المرفق تلقائيًا. من Sources → Browse all converted questions يمكنك تصفح التفريغ والبنود المعلّقة وأسباب تعليقها.
2. من «المصادر» استورد ملف الأسئلة المتحقق منه بالصيغة الموضحة في [دليل الاستيراد](docs/question-format.md).
3. اختر سنة المصدر، ثم «الدراسة» ← الموضوع ← الدرس. حدّد إجابتك واضغط «تأكيد الإجابة» ثم «متابعة».
4. «حفظ وخروج» يحفظ موضعك؛ «متابعة جلستك» في الرئيسية يستأنفه. لا تبدأ جلسة ثانية قبل إنهاء الجلسة الحالية.
5. احفظ الأسئلة بالنجمة، وراجع الأخطاء من «التقدم» ← «الأسئلة الضعيفة». السؤال الخاطئ يعود مرة في نهاية الدرس. يحتاج إلى مراجعتين صحيحتين يفصل بينهما يوم على الأقل ليُزال من الضعيف.
6. من «التدريب» اختر الموضوع والعدد والتوقيت. يستمر الوقت حتى عند إغلاق الصفحة. النتائج لا تظهر أثناء الاختبار.
7. صدّر نسخة احتياطية من «المصادر» دوريًا. الحفظ محلي لكل متصفح وعنوان موقع؛ لا توجد مزامنة بين iPhone وiPad. استخدم تبويب دراسة واحدًا في المرة. نقل النسخة يتم يدويًا باستيراد ملف النسخة الاحتياطية على الجهاز الآخر.

## التحقق والبناء

```sh
npm test
npm run build
# اترك خادم npm run dev يعمل في طرفية أخرى:
npm run test:browser
```

اختبار المتصفح يستخدم `/usr/bin/chromium` إذا توفر، أو متصفح Playwright. عند غيابه: `npx playwright install chromium`. يمكن تعيين `CHROMIUM_PATH` لمسار متصفح مثبت. يستخدم الاختبار رموزًا تقنية فقط في ملف متصفح مؤقت، ولا يضيف أسئلة تجريبية إلى التطبيق. صور الاختبار في `test-results/` مستبعدة من Git. نتيجة البناء في `dist/`، وهي مناسبة لاستضافة ملفات ثابتة. لم يُنشر التطبيق على رابط عام.

## الملفات المهمة

- [ملاحظات التنفيذ ودليل التسجيل وتقييم REA](docs/implementation.md).
- [جرد المصادر والوصول والخطوات المتبقية](docs/source-inventory.md).
- [صيغة الأسئلة ومسار مراجعة الاستخراج](docs/question-format.md).
- `src/model.js`: التحقق، المحاولات، المراجعة، الجلسات والإحصاءات.
- `src/app.js` و`src/style.css`: الواجهة والحفظ والتجاوب.
- `scripts/validate-import.js`: تحقق مستقل قبل الاستيراد.
- `scripts/extract-pages.py`: استخراج دليل صفحات PDF محددة مع إحداثيات وصور وبصمات للاستئناف. يحتاج PyMuPDF (متاح في بيئة العمل الحالية). يحفظ دليل صفحات محددة؛ للتحويل المجمع استخدم `scripts/convert-question-bank.py`.

لصفحات محددة من ملف أتاحه المستخدم:

```sh
python3 scripts/extract-pages.py /absolute/provided-folder/book.pdf --pages 12-14,28 --output private-sources/evidence
npm run validate -- /absolute/path/verified-package.json
```

أبقِ الكتب والنصوص المستخرجة ونسخ التقدم خاصة وخارج Git. لا تضع كلمات مرور أو جلسات LES داخل المشروع. الصيغ المعقدة تحفظ كنص المصدر أو صورة أصلية؛ هذه النسخة لا تعيد توليد الشروح ولا تحل الأسئلة الناقصة.

## اللغة والخط

الواجهة الإنجليزية هي الافتراضية؛ زر «العربية» يترجم الواجهة ويحفظ اختيارك. لا يترجم السؤال أو شرح المصدر. من Sources → Load Thmanyah font يمكنك تحميل ملف خط ثمانية المرخّص لك بصيغة WOFF2/WOFF/TTF/OTF. يُحفظ الملف في هذا المتصفح فقط. لم يُرفق خط ثمانية، والوصول إلى thmanyah.com محجوب من شبكة البيئة (403)، لذلك يستخدم التطبيق خط النظام حاليًا. لم يُستخدم خط آخر باسم ثمانية.

للتحقق من إدراج البنك وتبديل اللغة وتكبير الجدول وتشغيل حفظ التقدم، شغّل `node tests/language-browser.cjs` والخادم يعمل. الاختبار يفترض وجود ملف البنك الخاص محليًا. اختبارات `npm run test:browser` تعزل هذا البنك وتستخدم رموزًا تقنية.

## تجربة بدون تثبيت

شغّل `npm run portable` لإنشاء `releases/Madar-Study.zip`. فك ضغط الحزمة كاملة، ثم افتح `Madar-Study/Madar.html` في Chrome مع إبقاء مجلد `question-assets` بجانبه. التطبيق والأسئلة مدمجة في HTML؛ الصفحات الأصلية ملفات محلية مرفقة. تبقى بيانات التقدم في المتصفح؛ صدّر نسخة احتياطية قبل تغيير الجهاز أو مسار الملف. لا تتضمن هذه النسخة خط ثمانية غير المتوفر.

يتحقق `node tests/portable.cjs` من تحميل الحزمة والإجابة والتصحيح والاستئناف باستخدام ملفاتها المحلية دون اتصال خارجي. الاختبار عبر عنوان HTTP محلي مع اعتراض الطلبات؛ فتح `file://` نفسه محظور في متصفح بيئة الاختبار، لذا لم يُختبر النقر المزدوج على Windows هنا.

## التفريغ وأتمتة LES

أُنجز تفريغ أولي لـ1,558 بند سؤال من الكتب الأربعة عشر، مع النص الخام لكل الصفحات والوحدات وصور أقسام الأسئلة. حُوّلت البنود ذات مفاتيح الإجابة الصريحة المتوافقة إلى وضع الصفحات الأصلية؛ البنود غير الموثقة مستبعدة من التصحيح. راجع [التغطية ونتائج التحقق وحدود الأتمتة](docs/extraction-automation.md).

حزمة LES المحلية في `tools/les-capture`؛ على Windows شغّل `Run-LES.cmd` وسجّل الدخول بنفسك في Chrome. تحفظ المراجعات الموجودة دون بدء اختبارات جديدة. لم تُختبر على حساب LES الحقيقي بعد.

## نسخة مباشرة بلا فك ضغط

بعد `npm run portable` شغّل `python3 scripts/package-single-file.py` لإنشاء `releases/Madar-Open.html`. يحتوي التطبيق والبنك وصور الصفحات داخل ملف واحد؛ افتحه في Chrome دون مجلدات إضافية. حجمه نحو 80 MB. تبقى الصور الأصلية في البنك بمساراتها الثابتة، ويحوّل العرض الصور المدمجة إلى روابط Blob محلية عند الحاجة دون تغيير الأسئلة أو المحاولات.
