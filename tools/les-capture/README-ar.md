# التقاط مراجعات LES الموجودة

تعمل الأداة **على جهازك**؛ الجلسة السحابية الحالية لا تتصل بـChrome المحلي. تسجّل الدخول بنفسك في نافذة Chrome خاصة بالأداة. لا ترسل كلمة مرور أو رمز دخول أو Cookies. يُحفظ الدخول محليًا في `.les-profile`؛ لا تشارك هذا المجلد.

## التشغيل على Windows

1. ثبّت Node.js (الإصدار 22 أو أحدث) من https://nodejs.org إذا لم يكن مثبتًا.
2. فك ضغط الحزمة.
3. انقر مرتين على `Run-LES.cmd`. يثبّت المتطلبات في المرة الأولى ثم يشغّل الأداة. إذا أردت الأوامر يدويًا: افتح `cmd` في المجلد ونفّذ `npm ci` ثم `npm run capture`.
4. في نافذة Chrome الجديدة سجّل الدخول وافتح قائمة Practice المطلوبة. ارجع إلى نافذة الأوامر واضغط Enter عندما تظهر **Review Previous Attempt**.
5. أرفق مجلد **les-output** مضغوطًا بعد مراجعة محتواه. لا ترفق `.les-profile`.

لموضوع آخر:

```sh
npm run capture -- --url "https://learn.cfainstitute.org/courses/2127/external_tools/261" --output les-fixed
```

الرابط الافتراضي هو Fixed Income الظاهر في لقطة المستخدم. الأداة تعمل على المراجعات الموجودة في القائمة المختارة، ولا تكتشف موضوعات الحساب كلها تلقائيًا.

## الحدود

- تنقر فقط **Review Previous Attempt** و**Next Question** بالاسم الصريح. لا تبدأ Take/Retake ولا تنقر Restart Quiz/Submit/Continue/Next العام.
- تمنع طرق POST/PUT/PATCH/DELETE بعد تسجيل الدخول. إذا كان عرض المراجعة نفسه يحتاجها تتوقف بدل السماح بطلب غير مفحوص؛ قد يمنع ذلك تجديد الدخول أو بعض واجهات القراءة أيضًا.
- قد تعرض الصفحة سؤالًا واحدًا أو كل الوحدة. عدد اللقطات ليس عدد الأسئلة. لا نفترض أن الحلول أو Pack ظاهرة دائمًا.
- تحفظ نصوصًا وصور شاشة وبصمات تمنع تكرار اللقطات عند إعادة التشغيل. لا تستنتج إجابات ولا تستورد السجلات إلى التطبيق تلقائيًا.
- اختُبرت الأداة على صفحة اختبار محلية فقط. **لم تُختبر على LES الحقيقي** لغياب اتصال المتصفح. قد تحتاج أسماء الأزرار وبنية الإطارات إلى ضبط بعد أول تشغيل.
- المخرجات قد تحتوي اسم الحساب وأسئلته الظاهرة؛ راجعها قبل المشاركة. لا يُحفظ ملف Cookies أو إعدادات الدخول ضمن المخرجات.
