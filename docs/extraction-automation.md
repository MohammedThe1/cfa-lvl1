# أتمتة التفريغ — 2026-10-27

## النتائج الفعلية

شُغّل `scripts/transcribe-books.py` على الكتب المرفقة الأربعة عشر. حُفظ نص **5,382 صفحة**، وأرشيف نص كامل لكل من **204 وحدات/Readings** (102 CFA + 102 Schweser، دون ملحق Quant). فُصلت آليًا **1,558 بندًا مرشحًا كأسئلة: 949 CFA + 609 Schweser**.

هذه أعداد فصل آلي وليست ضمانًا لاكتمال كل سؤال بصري أو سلامة صيغته. من 1,558 سجلًا، 1,512 لها ثلاثة خيارات مرشحة؛ البقية تضم أسئلة مفتوحة أو مطابقة أو حالات تحتاج مراجعة التخطيط. جميع السجلات حالتها `review` والإجابة الصحيحة فيها `null`؛ لا يُحل السؤال أو تُستنتج إجابته آليًا. ملفات أقسام الحلول محفوظة منفصلة، دون ربط تخميني لكل سؤال. لم تُضف هذه الدفعة إلى بنك التطبيق المسجل؛ يظل البنك الموثق السابق 11 سؤالًا.

### حدود التغطية

- أقسام Practice Problems في CFA، وعناوين Module Quiz المفردة والمجمعة في Schweser، منفصلة في ملفات قابلة للبحث.
- **Ethics LM10 Application of the Code and Standards** لا يحتوي عنوان Practice Problems مستقلًا في الفهرس؛ نص حالات الوحدة كامل محفوظ بدل اختراع بنك منفصل.
- الأمثلة المحلولة والأسئلة المتناثرة داخل الشرح محفوظة في النص الكامل للوحدات، لكن لم تُفصل جميعها كسجلات مستقلة. لذلك لا يُدّعى أن كل سؤال بصري/ضمني في الكتب تحوّل إلى سجل منظم.
- الجداول والأشكال والمعادلات قد لا تمثلها طبقة النص تمثيلًا كاملًا؛ صور صفحات أقسام الأسئلة مرفقة. لا حاجة إلى OCR عام قبل تحديد صفحات صور بلا طبقة نص مفيدة.
- الحفاظ على النص الخام يعني بقاء بعض ترويسات الصفحات وشرطات تقسيم الكلمات. لا تُغيّر الكلمات تخمينيًا.

## التشغيل والاستئناف

```sh
python3 scripts/transcribe-books.py \
  --inventory private-sources/review/inventory.json \
  --output private-sources/transcripts
```

عند نقل المصادر يمكن تحديد مجلد صريح بواسطة `--source-dir`. لا تفحص الأداة مجلدات خارج هذا المسار بحثًا عن الكتب. يجب أن يطابق كل اسم ملف مصدرًا وحيدًا وبصمة SHA-256 الموجودة في الجرد. الملفات الخام المخزنة لها بصمات تحقق مستقلة قبل إعادة استخدامها. صور الصفحات القائمة تُحفظ عند التكرار. المعرّفات مشتقة من بصمة المصدر والوحدة والقسم وترقيم السؤال.

المخرجات لكل كتاب: `questions.html` للقراءة، `questions.md` للنص، `module-*-fulltext.txt` لكل الوحدة، `module-*-section-*.txt` للأقسام، `module-*-answers.txt` للحلول، `all-pages.jsonl` لكل صفحات المصدر و`pages/` للصور. ملخص التغطية في `manifest.json` و`coverage.csv`، والسجلات في `question-candidates.jsonl`.

## التحقق المنفذ

- التحقق من وجود الصفحات الـ5,382 وترتيبها الكامل في الأرشيف الخام.
- فحص تفرد المعرّفات الـ1,558.
- مطابقة عدد البنود في أقسام CFA الـ101 مع أقصى ترقيم صريح في أقسام الحلول؛ تطابقت جميعها. هذه مطابقة أعداد لا مطابقة كل كلمة.
- أثناء التطوير عولجت قوائم الأرقام الفرعية وأرقام الرسوم التي كانت تُلتقط كأسئلة، وعناوين Module Quiz المشتركة، وحالة سؤال يبدأ نصه في السطر التالي.
- نجحت 3 اختبارات لحدود الفصل باستخدام رموز تقنية: الأرقام الفرعية وأرقام الرسوم والسؤال الذي يبدأ في السطر التالي؛ لا تصنع هذه الاختبارات أسئلة دراسية.
- فحص تكرار التشغيل مع إعادة استخدام النصوص المحفوظة وعدم تغيير بنك التطبيق.
- تقرير التفاصيل: `private-sources/transcripts/verification-report.json`.

## أداة LES المحلية

`tools/les-capture` حزمة مستقلة تعمل على جهاز المستخدم. بعد تسجيل دخوله بنفسه في Chrome، تقرأ عناصر **Review Previous Attempt** الموجودة بالقائمة المختارة ثم **Next Question** إن كان هذا الاسم الصريح موجودًا. تحفظ النص المرئي وصورًا وبصمات، ولا تنقر Take/Retake/Restart/Submit/Continue. تمنع طرق الشبكة غير GET/HEAD/OPTIONS بعد تسجيل الدخول؛ إذا احتاجت المراجعة POST تتوقف لطلب فحص مخصص بدل السماح به.

الأداة تحتاج Node.js 22+ وChrome. على Windows افتح `Run-LES.cmd`. تعليمات كاملة في `tools/les-capture/README-ar.md`. تشغيلها محليًا لا يمنح السحابة قناة تحكم ولا يشارك ملف الدخول تلقائيًا. أرسل المخرجات فقط بعد مراجعتها، لا مجلد `.les-profile`.

**الاختبار الفعلي:** نجح اكتشاف مراجعتين والتنقل إلى ثلاث لقطات، وإعادة التشغيل دون مضاعفة السجلات، وحجب POST مع صفر طلبات إرسال وصلت إلى خادم الاختبار. هذا اختبار محلي؛ لم يُفتح حساب LES الحقيقي بأدوات السحابة. اختلاف أسماء الأزرار أو واجهة LES قد يستلزم ضبط الأداة بعد أول تشغيل. لا توجد مطالبة بأن الأداة استخرجت حساب المستخدم أو جميع أسئلة Practice Pack.
